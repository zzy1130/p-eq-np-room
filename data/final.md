# 会话 pnp-20261112 终稿：证明 P=NP（至第 2 轮）

## 一、总体结论（否定性结论）

**本会话至第 2 轮未证明 P = NP。** 不存在任何已通过审查的一般 3-SAT 确定性多项式时间算法，也不存在任何被验证为完整 P = NP 证明的主张。

已确立的实质成果仅两项，且均不能单独推出 P = NP：

1. **C3（分量分解正确性引理）**：通过，但仅为判定等价性引理，不含任何时间界。
2. **C4（相关变量规范化编码与以输入位长为规模的多项式时间标准）**：未被有效反驳，作为**规约约定**保留，非定理。

被退回的主张（不得写入终稿为定理）：

- **C2**：在输入位长标准下把 `n` 或 `n+m` 当规模参数，属伪多项式/表示敏感失败。
- **C5**：预处理已修正，但完整赋值列表输出破坏位长多项式性。
- **C6**：正确性成立，但条件多项式边界未被证明；分量分解 + 局部枚举只是 CSP 有界宽度结果的特例。

**核心障碍**：真正的卡点不是分量分解的正确性，而是超宽/高树宽分量的枚举代价 `2^{w_i}` 缺乏位长级多项式界（未被证明一般 3-SAT 可多项式归约为对数宽度/低树宽实例）；此外接口层面的 `O(n_vars)` 完整赋值输出破坏位长多项式性（该点在 C5 阶段成立，C6 改用 `bool` 接口后已消除，属历史失败点）。

## 三、通过条目及其严格边界

### C3 — 分量分解正确性引理（通过）

**命题**：对合法 3-SAT 实例，在相关变量集 `V_rel = {v : v 出现在某子句中}` 上按「同一子句中的变量属于同一分量」建立连通分量 `P_1,…,P_t`，则

> 原公式可满足 ⟺ 每个分量对应的局部公式可满足。

**审查结论**：第 1 轮经反例猎手（未构造出有效反例）与壁垒审查通过。该引理在合法输入下成立，关键依据为：(1) 每个子句的全部变量被合并到同一分量；(2) 不同分量变量域互不相交；(3) 未出现在子句中的变量不影响判定。

**严格限定**：C3 只保证「按分量求解再合并」的判定等价性。它**不**证明宽分量可在多项式时间求解，**不**证明任意 3-SAT 可多项式归约为小宽度分量，**不**推出 P = NP。其通过仍依赖「每个子句恰含三个文字」的输入合法性约定。

### C4 — 规约约定（保留为方法论标准，非定理）

C4 规定后续所有算法/反驳必须遵守：

1. 只把出现在子句中的相关变量纳入求解规模，`r ≤ 3m`；
2. 以原始输入位长 `|x|` 或规范输入位长 `|x'|` 为多项式时间标准，禁止把原始 `n` 直接当规模参数；
3. 禁止显式初始化/遍历/枚举未出现在子句中的变量（否则须证明该开销相对 `|x|` 仍是多项式）；
4. 对分量枚举类算法，须以位长级界 `Σ_i 2^{w_i}·poly(m) ≤ poly(|x'|)` 证明枚举总量多项式；
5. 须同时给出 `|x|` 级时间与空间上界；
6. 正确性引理与复杂度结论必须分开。

C4 是对 C1 易诱发伪多项式漏洞的修补，尚未经过完整反例/壁垒审查，因此仅作规约约定写入，不作定理。

## 四、退回条目及失败点

### C2 — 已退回（伪多项式/表示敏感失败）

**失败点**：C2 把 `n` 或 `n+m` 当规模参数。反例：取 `n = 2^N, m = 1, C_1 = (x_1∨x_2∨x_3)`，输入位长 `|x| = Θ(log n) = Θ(N)`，最大分量宽度仅 3，满足 `W = O(log(n+m))`，但 C2 的实现显式建立大小为 `n` 的数组并遍历 `1..n`，运行时间 `Ω(n) = 2^{Ω(|x|)}`。即使宽度满足对 `n+m` 的对数界，枚举项 `2^{W_i}` 也可达 `2^{Ω(|x|)}`。

**支持退回**：算法设计者 B、复杂度分析、文献核查一致。该退回不被否定分量分解本身的正确性。

### C5 — 已退回（完整赋值输出破坏位长多项式性）

**已修正部分**：C5 吸收了 C4，只处理相关变量、不遍历 `1..n`，消除了 C2 的直接伪多项式失败点。

**残留失败点**：C5 仍执行 `assignment = [0] * n_vars` 并返回长度 `n_vars` 的完整列表。取 `n = 2^N, m = 0`（或 `m = 1`）时，`|x| = Θ(N)`，仅构造该输出即需 `Ω(n) = 2^{Ω(|x|)}` 时间与空间。因此当前接口下 C5 整体不是最坏情况多项式时间。

**修补要求**：改为 `bool` 判定接口 `solve_3sat(n_vars, clauses) -> bool` 或稀疏赋值接口 `solve_3sat_sparse(...) -> dict | None`，删除完整列表展开。

### C6 — 已退回（条件多项式边界未获证明）

**正确性**：C6 复用 C3 且改用 `bool` 接口，消除了 C5 的输出开销，正确性成立（停止性 + SAT/UNSAT 判定正确）。

**退回理由**：文献核查有效反驳——分量分解 + 局部枚举只是 CSP 有界宽度结果的特例，真正决定多项式性的是 treewidth / pathwidth / hypertreewidth，而非分量变量数 `w_i`。C6 的条件 `Σ_i 2^{w_i}·poly(m) ≤ poly(|x|)` 仅对低宽度实例成立；链式实例族

```
(x1∨x2∨x3),(x3∨x4∨x5),(x5∨x6∨x7),…
```

把所有相关变量并成 `w = Θ(m)` 的单分量，枚举 `2^{Θ(m)}` 超多项式。未证明一般 3-SAT 可多项式归约到低宽度/低树宽实例前，C6 不能作为 P = NP 候选算法。

**状态更正**：第 2 轮「壁垒审查」曾写 `STATUS: C6 | 通过`，此标记**不合法，不予采纳**。第 2 轮反例猎手发言失败、C6 复杂度部分未获完整审查，且 C6 已被文献核查有效反驳；「未命中三大已知障碍」不等于「通过」。C6 退回。

## 五、核心障碍分析

分量枚举路线（C2/C5/C6）的失败点高度一致：

1. **结构参数选择错误**：以分量变量数 `w_i` 为核心参数不足；文献中应以 treewidth / pathwidth / hypertreewidth 等分解宽度衡量可控性。
2. **枚举代价缺位长级界**：`Σ_i 2^{w_i}` 缺乏 `poly(|x|)` 上界，未被证明一般 3-SAT 可多项式归约为对数宽度/低树宽实例。
3. **输出接口破坏多项式性**：`O(n_vars)` 完整赋值输出在 `n` 相对 `|x|` 指数大时单独即 `2^{Ω(|x|)}`（C5 阶段成立；C6 改用 `bool` 后已消除，属历史失败点）。

三大已知壁垒（相对化 BGS 1975、自然证明 Razborov–Rudich 1997、代数化 Aaronson–Wigderson 2008）均**未被命中**：本实验所有方法均为显式有限枚举与分量分解，未使用 oracle 模拟、对角化、自然性质电路下界或算术化技术。本实验的障碍是**复杂度证明缺口**，而非已知不可行技术类别。

## 六、本终稿确立的内容与未确立的内容

**已确立**：

1. C3 作为分量分解正确性引理（限判定等价性）。
2. C4 作为以输入位长为规模标准的规约约定。
3. C1 作为工作基准（精确 3-SAT + 最坏情况多项式时间 + 位长编码）。

**未确立（不得写入为定理）**：

1. 任何一般 3-SAT 的多项式时间算法。
2. 任何将 C3/C4 升级为 P = NP 证据的论证。
3. 任何绕过超宽/高树宽分量 `2^{w_i}` 枚举障碍的机制。

## 七、后续轮次须正面回答的问题

1. 是否证明「任意 3-SAT 可多项式时间归约为分量宽度满足 `Σ_i 2^{w_i}·poly(m) ≤ poly(|x|)` 的实例」？若否，分量枚举路线不能作为 P = NP 证据。
2. 若引入树分解/超树分解，须给出 treewidth / hypertreewidth 与 `|x|` 的多项式关系，而非仅给出分量大小。
3. 任何新算法须同时给出 `|x|` 级时间与空间上界，并避免 `O(n_vars)` 输出。
4. 若声称 DPLL/CDCL 多项式，须正面处理 resolution 指数下界（Haken 1985；Ben-Sasson–Wigderson 2001）。
5. 若声称 SDP/SoS 多项式，须给出层级、运行时间、integrality gap 说明。
6. 若从 2-SAT 推广到 3-SAT，须给出从一般 3-SAT 到可处理子类的多项式保真归约。
7. 平均情况/随机实例的高概率成功不等于最坏情况多项式。
