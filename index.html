AI 圆桌 & 辩论厅

四位人格辩手按 Policy/CX 赛制正反交锋，或由多个角色围坐圆桌讨论。每一场都实时直播、可随时回放，辩论结束由裁判宣判并出具赛后报告。

怎么运作

  1. 提交辩题并选人格辩手

    正反方各 2 个席位，可以指定人格辩手；没选的位置由分配官自动补齐角色与 skill。

  2. 四位辩手按 Policy/CX 赛制实时交锋

    立论、质询、反驳依次进行，全程直播，模型经 pi-agy 调用 Gemini Flash。

  3. 裁判宣判并生成 HTML / PDF 赛后报告

    Gemini 传令官按量表评分；180 秒内未回复时，由 Claude Code CLI 兜底裁判。

观战走实时通道；实时通道连不上时，页面自动切换到 GitHub Pages 快照，约每分钟更新一次。
